CONFIGURACIÓN
- config.js incluye el LOCALIZADOR de SharePoint proporcionado; no contiene contraseñas.
- Microsoft 365 (MSAL) y Microsoft Graph conservan la autenticación delegada.
- Toda autorización efectiva depende de los permisos asignados en SharePoint/Entra ID.
- Verifique que el enlace compartido no sea accesible para "Cualquiera con el vínculo".
- Mantenga el dominio/URL de GitHub Pages registrado como Redirect URI SPA de Entra ID.

INTERFAZ V1.1
- Se eliminó el panel de carga local Excel/JSON y los controles manuales de índice,
  OCR, conexión, activación semántica y publicación de novedades.
- Se conserva "Actualizar datos" como acción de recuperación: carga al iniciar sesión.
- Se sustituyó Analítica histórica por Trazabilidad de decisiones: una secuencia
  documental cronológica, filtrable por asunto, con fichas y enlaces al acta.
- La actualización ahora se muestra con diálogo CENTRAL de estado, etapas,
  progreso y opción "Continuar explorando" para procesos prolongados.
- Los errores de conexión se muestran en el diálogo, no solo mediante notificaciones efímeras.
- Pie de página con crédito del desarrollador Jair Cruz y enlace a LinkedIn.
- El asistente mantiene sus referencias documentales: no se anuncian resúmenes
  generativos que no se hayan implementado. La semántica local se prepara bajo demanda.

FUNCIONAMIENTO DE DATOS
- El índice privado se lee desde SharePoint al autenticarse.
- La matriz se obtiene de SharePoint al iniciar sesión o "Actualizar datos".
- El repositorio se revisa por cambios y solo se procesan nuevas actas.
- El procesamiento OCR se hace en el navegador, mientras la web está abierta.
- La publicación automática del índice depende de Files.ReadWrite delegado.
- Ante cambios de ETag o falta de permisos NO se fuerza una sobreescritura;
  se informa de la incidencia. No hay vigilancia ni trabajo en segundo plano.

COMPROBACIONES REALIZADAS
- Código JavaScript comprobado con node --check.
- Contratos DOM estáticos contrastados y funciones de trazabilidad/progreso
  comprobadas con una prueba Node.js.
- No se han podido probar con una cuenta FIAS la conexión real Graph, OAuth,
  el OCR de nuevos PDF ni los permisos de publicación del índice.

PRECAUCIÓN: GitHub Pages publica los archivos .js, .html, .css y config.js de forma
pública. Nunca almacene allí tokens, secretos, claves ni archivos privados.
