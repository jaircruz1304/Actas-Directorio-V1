FUENTE CENTRAL · SHAREPOINT PRIVADO

Índice histórico conectado

Conexión directa y automática al índice institucional desde Microsoft 365. El sistema verifica versiones al iniciar sesión y al sincronizar, sin configurar enlaces por usuario.

Conexión automáticaConecta Microsoft 365 para consultar el índice institucional.
↗ Abrir índice privado

Las actas nuevas se procesan al sincronizar y se intentan publicar automáticamente con permisos de edición y consentimiento Files.ReadWrite. Si faltan permisos o cambia la versión del archivo, se mantiene el respaldo local y se ofrece publicación manual.

RESPALDO MANUAL
El localizador del índice está preconfigurado en config.js, público por ser GitHub Pages; no es un secreto. El contenido se descarga autenticado desde SharePoint y se conserva en caché por perfil Microsoft 365. Restringir permisos en SharePoint.
